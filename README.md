# docker-ecr-ecs-alb-ec2
Deploy a Web Application on AWS ECS using EC2, Docker, ECR &amp; Load Balancer
This repo guides you to containerize a web application, push it to AWS ECR, create an ECS cluster on EC2, deploy the app, and expose it via a load balance.
